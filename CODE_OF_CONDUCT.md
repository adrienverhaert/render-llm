# Code of conduct

Treat contributors respectfully. Technical disagreement is welcome; harassment,
discrimination, threats, sexual attention and publication of another person's
private information are not.

Discuss the work and explain disagreements with evidence. Accept corrections,
respect project scope, and keep issues and pull requests relevant to the project.

Maintainers may edit or remove harmful content, close disruptive discussions or
restrict participation. To report a concern privately, request a private channel
without posting sensitive details in an issue. Maintainers should protect the
reporter's privacy and respond proportionately to the behavior.
